# Real Estate Website

A modern and responsive Real Estate Website built using HTML, CSS, and JavaScript.  
This project showcases property listings, testimonials, services, animated sections, and interactive sliders using Swiper.js and GSAP.

---

## Features

- Responsive Navigation Bar
- Modern Landing Page
- Property Listings Section
- Testimonials Slider
- About Section
- Real Estate Services Section
- Animated Image Gallery
- Swiper.js Carousel
- GSAP Animations
- Contact Alert Popup
- Responsive Design

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP
- Swiper.js
- Font Awesome
